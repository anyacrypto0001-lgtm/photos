Version 2.2.0 · for Windows 10 and 11

What's new: Download from the website and update inside the booth

Download Le Petique

210 KB

  1. Right-click the downloaded file and choose Extract All. Put it in a new folder, for example on the Desktop (not in Program Files).
  2. Open LePetique.exe. If Windows says Windows protected your PC, click More info, then Run anyway.
  3. Allow the camera when asked.
  4. Open the settings button and go to Booth to change the PIN (it starts as 1234).

Already have it? You don't need to download again: the booth shows Update available in Settings → Booth → About and updates.
